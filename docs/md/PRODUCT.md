# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Astro static and TypeScript, approved by the user. GitHub Pages hosts the public product website.

## Users

Women evaluating Cecilia for understanding menstrual cycles and fertility signs, including people visiting an iOS beta invitation.

## Product Purpose

Explain the app's existing objective and features, then help visitors join its iOS TestFlight open beta.

## Capabilities and Constraints

English, neutral Latin American Spanish, and Brazilian Portuguese. The main address follows supported browser languages and otherwise uses English. Direct language addresses are stable. No backend, analytics, contact form, pricing, or custom domain is required.

Cecilia supports period and daily observation logging, daily fertility guidance, a calendar, temperature charts, and calendar/symptothermal methods. Forecasts are not a contraceptive guarantee. Copy must preserve the app's existing disclaimer and must not invent clinical accuracy, pricing, or privacy claims.

## Brand Commitments

The user approved extending the app's cream/plum identity, five-color cycle-ring wordmark, typography, and real app screenshots. The implementation is built directly, without image mockups.

## Evidence on Hand

Localized iOS screenshots from the app's evidence gallery use test/example data. Website assets preserve these screens and label them as examples. The public TestFlight invitation is approved and verified.

## Accessibility & Inclusion

Readable contrast, keyboard navigation, semantic landmarks, descriptive image alternatives, responsive layouts, and reduced-motion support.
